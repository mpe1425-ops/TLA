Тест личностных акцентуаций (ЛА) — автоматическая обработка

По методике В.П. Дворщенко (модификация ПДО А.Е. Личко), 2002. Данные обрабатываются в браузере и никуда не отправляются.

Параметры обследуемого

Пол нужен для правила «М < Ф» (применяется только к юношам). Для пакетной обработки параметры общие.

1. Загрузить файл (CSV / XLSX)

Допустимы: строка из 195 значений; столбец из 195 значений; два столбца «№ — ответ»; несколько строк (по одному обследуемому в строке, первая ячейка может быть ФИО). Значения от −3 до +3.

2. Вставить из Excel / текста

3. Заполнить бланк

Введите ответ для каждого утверждения: от −3 до 3. Enter / пробел / Tab — к следующей ячейке. Пустые ячейки считаются как 0.

Ключи шкал

Формат: «ДА» и «НЕТ» — номера пунктов через пробел; вес, если он не 1, указывается через двоеточие (85:2, 96:-3). Ответ +3 засчитывается по ключу «ДА», −3 — по ключу «НЕТ». Изменения действуют до перезагрузки страницы (можно сохранить в JSON).
